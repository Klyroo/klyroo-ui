# Documentation

The documentation follows the [Diátaxis](https://diataxis.fr/) split: a tutorial to start, how-to guides for tasks, a
reference that is generated from the code, and an explanation of the concepts.

## Tutorial

- [Getting started](getting-started.md): install the package, register it, load the styles and build a validated form.

## How-to guides

- [Guides](guides.md): palettes and tokens, restyling, Tailwind, fonts, icons, images, localization, forms, color mode and testing.

## Reference

- [API reference](api-reference.md): every public type and member of the four packages, generated from the code.
- [Platforms](platforms.md): render modes, .NET MAUI Blazor Hybrid, trimming and NativeAOT.
- [FAQ](faq.md): troubleshooting, known limitations and frequent questions.

## Explanation

- [Concepts](concepts.md): slots and themes, the `Ui` and `Class` overrides, the two stylesheet modes, and how the browser and .NET share the work.

The [README](../README.md) lists the components and the packages. [CHANGELOG.md](../CHANGELOG.md) lists the releases.
