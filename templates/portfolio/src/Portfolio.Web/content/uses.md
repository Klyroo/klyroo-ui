A page like this goes out of date quickly, so the list is short and I change it when something changes. It is served by `content/uses.md`, a plain Markdown page, and you can write one the same way.

## Hardware

- A 14 inch laptop with 32 GB of memory, which I use docked at the studio and on its own everywhere else.
- A 27 inch monitor that I calibrate every year, and a second, cheaper one that I keep uncalibrated to see what most people see.
- A mechanical keyboard with quiet switches, because the studio is shared.
- An old Android phone with a cracked screen, kept for testing on a slow device.

## Software

| Purpose | What I use |
| --- | --- |
| Editor | Visual Studio Code, with few extensions |
| Design | A vector editor, and paper for the first sketch |
| Browsers | Firefox for daily use, Chromium and Safari to test |
| Terminal | A plain terminal with a short prompt |
| Notes | Plain Markdown files in a folder, with git |
| Accessibility | A screen reader on each platform, and axe in the tests |

## Code

I write TypeScript and C#. For the web I like [Blazor](https://example.com/blazor) when the team already works in .NET, and web components with a little TypeScript when it does not. Tests are run by Playwright, with axe on every page in light and in dark mode.

```bash
dotnet watch --project src/Portfolio.Web
```

## Habits

I keep my phone in another room while I work, I walk before lunch, and I write the plan for tomorrow before I close the laptop. None of these is a system. They are the only things that survived the year I tried a lot of systems.
